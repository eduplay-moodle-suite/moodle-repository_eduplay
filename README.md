## English

File picker repository of the [EduPlay Moodle Suite](https://github.com/eduplay-moodle-suite): search [EduPlay](https://eduplay.rnp.br/) videos by title (with thumbnails, paged) or paste a video link, and get an external link (no media is copied), shown as the official player by [`media_eduplay`](https://github.com/eduplay-moodle-suite/moodle-media_eduplay). It uses the public (undocumented) EduPlay API through `local_eduplay` 0.3.0, which can be switched off. Requires `local_eduplay`. Supports Moodle 4.5 LTS and 5.3 LTS.

> Unofficial project: no affiliation with RNP, EduPlay or Moodle HQ.

Install this repository in `repository/eduplay` (`public/` prefix on Moodle 5.1+), visit *Site administration > Notifications* and enable it in *Manage repositories*.

## Português (Brasil)

Repositório do seletor de arquivos da [EduPlay Moodle Suite](https://github.com/eduplay-moodle-suite): pesquise vídeos do [EduPlay](https://eduplay.rnp.br/) pelo título (com miniaturas e paginação) ou cole o link de um vídeo e receba um link externo (nenhuma mídia é copiada), exibido como player oficial pelo [`media_eduplay`](https://github.com/eduplay-moodle-suite/moodle-media_eduplay). Usa a API pública (não documentada) do EduPlay por meio do `local_eduplay` 0.3.0, que pode ser desligada. Requer `local_eduplay`. Suporta Moodle 4.5 LTS e 5.3 LTS.

> Projeto não oficial: sem afiliação com a RNP, o EduPlay ou o Moodle HQ.

Instale este repositório em `repository/eduplay` (prefixo `public/` no Moodle 5.1+), acesse *Administração do site > Notificações* e habilite-o em *Gerenciar repositórios*.
