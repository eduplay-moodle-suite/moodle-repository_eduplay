## English

Proof of concept of a file picker repository for the [EduPlay Moodle Suite](https://github.com/eduplay-moodle-suite): paste an [EduPlay](https://eduplay.rnp.br/) video link in the search box and get it back as an external link (no media is copied), shown as the official player by [`media_eduplay`](https://github.com/eduplay-moodle-suite/moodle-media_eduplay). There is no catalogue browsing: EduPlay has no officially confirmed listing API. Requires `local_eduplay`. Supports Moodle 4.5 LTS and 5.3 LTS.

> Unofficial and experimental project: no affiliation with RNP, EduPlay or Moodle HQ.

Install this repository in `repository/eduplay` (`public/` prefix on Moodle 5.1+), visit *Site administration > Notifications* and enable it in *Manage repositories*.

## Português (Brasil)

Prova de conceito de repositório do seletor de arquivos da [EduPlay Moodle Suite](https://github.com/eduplay-moodle-suite): cole o link de um vídeo do [EduPlay](https://eduplay.rnp.br/) na busca e receba-o como link externo (nenhuma mídia é copiada), exibido como player oficial pelo [`media_eduplay`](https://github.com/eduplay-moodle-suite/moodle-media_eduplay). Não há navegação no catálogo: o EduPlay não tem API oficial de listagem confirmada. Requer `local_eduplay`. Suporta Moodle 4.5 LTS e 5.3 LTS.

> Projeto não oficial e experimental: sem afiliação com a RNP, o EduPlay ou o Moodle HQ.

Instale este repositório em `repository/eduplay` (prefixo `public/` no Moodle 5.1+), acesse *Administração do site > Notificações* e habilite-o em *Gerenciar repositórios*.
